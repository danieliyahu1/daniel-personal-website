Journeys

How I got here — a path through web apps, full-stack systems, and into blockchain and AI.

Web foundations

Started by building the classic first projects — games, booking apps, and management systems. The details are different, but the instinct is the same: see a problem, build the thing.

Full-stack systems

Moved into the MERN stack and larger systems: booking platforms, college management, patient management. Learning to think in data models, APIs, and real users.

Microservices & AI

Docker-first architecture with React frontends, Spring Boot backends, and AI model integrations behind an API gateway. Where engineering discipline meets machine intelligence.

Blockchain

Deep into the Kaspa ecosystem — contributing to its REST infrastructure, then building covenant-bound assets, on-chain ticketing, and printable transaction statements.

AI tooling

Bringing it together: MCP servers that let AI assistants read blockchains, and plugins that let people control their AI tools from anywhere. The gap between the two worlds is exactly where the interesting work lives.
